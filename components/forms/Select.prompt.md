Labelled native select with a brand chevron. Pass `<option>`s as children.

```jsx
<Select label="How often?" defaultValue="biweekly">
  <option value="once">One-time</option>
  <option value="weekly">Weekly</option>
  <option value="biweekly">Every 2 weeks</option>
  <option value="monthly">Monthly</option>
</Select>
```

- Supports `hint` and `error` like Input.
